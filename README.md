## 🚀 Key Features Shipped

1. **Interactive 3D WebGL Hero Canvas (`three-scene.js`)**:
   - 3D Wireframe Torus Knot with glowing concentric orbital rings.
   - 1,800-point particle constellation with real-time cursor physics & mobile touch inertia.
   - Dynamic lerp damping for 60 FPS performance.

2. **Who We Are & What We Do (About Us Bento Grid)**:
   - Dual-model breakdown (Product Lab × Freelance Powerhouse).
   - Interactive Live Terminal with executable diagnostic simulator (`tagx-cli`).
   - Technical standards: Zero-AI Slop, Human-grade craft, 100/100 Lighthouse performance.

3. **Services Matrix (What and All We Do)**:
   - `01` — 3D WebGL & Modern Animated Web Frontend.
   - `02` — In-House Software Products & Native Desktop Tools.
   - `03` — Enterprise Backends, High-Concurrency APIs & Cross-Platform Mobile Apps.

4. **Product Download Hub (`downloads` section & modal)**:
   - Flagship Products Showcase: **TAGX Pulse™**, **TAGX Forge Studio™**, **TAGX Sentinel™ CLI**, and **TAGX Flow DB™**.
   - Operating system filter tabs: All Releases, Windows (`.exe`), macOS (`.dmg`), Linux (`.deb`/`.tar.gz`).
   - Download Modal with simulated verified progress bar packaging that triggers actual downloadable installer files in the user's browser.
   - One-click copy `curl` terminal installation command with toast feedback.

5. **⌘K Command Palette (`Ctrl+K` / `Cmd+K`)**:
   - Quick navigation search to jump directly to any section or download.

6. **Freelance & Client Service Brief Transceiver**:
   - Interactive project intake brief with service domain selector and submission feedback.
